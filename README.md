# Smart Research Library 1.0

Демонстрационный прототип цифровой научной библиотеки для Научной библиотеки ЕНУ им. Л. Н. Гумилёва. В нём два кабинета — магистранта или докторанта и сотрудника библиотеки — с виртуальным библиотекарем, научным паспортом, поиском литературы, планером и библиотекой научных промптов.

> Это прототип для демонстрации идеи проекта, а не официальный сервис ЕНУ. Пользователи, обращения и статистика в нём демонстрационные.

**Сайт:** https://smart-research-library.pages.dev — Cloudflare Pages, обновляется после каждого push в `main`.

**Демо с ИИ:** https://claude.ai/artifact/HfLXFyYYa8qYRMhvfb6g69 — в этой версии работают генерация ответов ИИ и общая база данных.

## Возможности

**Кабинет исследователя**

- **Научный паспорт** (AI Research Passport) — профиль исследователя, ORCID с проверкой контрольной цифры, научные интересы, публикации и настройки видимости.
- **Подбор темы** (AI Topic Finder) — по интересам подбирает 3–4 утверждённые темы ЕНУ по специальности 8D01103 «Педагогика и психология» (42 темы, 2019–2025) с объектом, предметом, научной новизной и статистическим аппаратом. Есть база тем с фильтром по году и поиском. ИИ помогает сформулировать собственные варианты с гипотезой. База и логика подбора перенесены из PhD AI Navigator ENU.
- **Поиск литературы** (Research Search Bot) — поиск по каталогу из 40 реальных публикаций с DOI и конструктор запросов для Scopus, Web of Science и PubMed.
- **Моя библиотека** (Smart Library Bot) — коллекции и оформление ссылок по ГОСТ, APA, Vancouver, а также экспорт в BibTeX и RIS.
- **Виртуальный библиотекарь** (AI Library Assistant ENU) — отвечает по подтверждённой базе знаний. Если ответа нет, создаёт заявку библиотекарю со статусами «Ожидает» → «В работе» → «Решено».
- **Научный планер** (AI Academic Planner) — план работы по семестрам, встречи с руководителем и ежемесячный отчёт.
- **Экспертная комиссия** (AI Expert Commission) — докторант приглашает научного руководителя, зарубежного консультанта, профессоров, внутренних и внешних экспертов, членов комиссии предзащиты; у каждого свой код доступа к выбранным главам. Эксперт оставляет замечание → докторант получает уведомление, ИИ объясняет замечание и предлагает шаги → докторант прикладывает новую версию главы → эксперт подтверждает или возвращает. Сводная таблица «Замечаний · Исправлено · Осталось» и предварительный ИИ-анализ по экспертным критериям. ИИ не принимает решение о допуске к защите.
- **Библиотека промптов** (AI Prompt Library) — 28 промптов для этапов исследования, в том числе статья для журналов из перечня КОКСОН на русском и казахском языках, проверка научной новизны и цепочка PRISMA 2020 из 9 шагов.
- **Развитие платформы** — дорожная карта и бета-модули AI Journal Finder, AI Reviewer Simulator и AI Academic Translator.

**Кабинет эксперта комиссии** — рецензирование доступных глав, замечания, проверка исправлений и сводка комиссии.

**Кабинет сотрудника библиотеки**

- Обзор и аналитика (Library Staff Dashboard), обращения, база знаний, мероприятия и консультации, ресурсы и уведомления.

## Как открыть

Откройте `dist/index.html` в браузере — это один самодостаточный файл. Демо-данные хранятся в браузере.

Интерфейс по умолчанию светлый (дневная тема). Переключатель в верхней панели включает дневную или вечернюю тему либо режим «по времени суток»: с 7:00 до 19:00 — дневная тема, в остальное время — вечерняя. Выбор запоминается в браузере.

У каждого раздела свой цвет и фоновый мотив; шрифты — Rubik (заголовки) и Nunito (текст). Выполненное отмечено зелёным, невыполненное — красным: этапы планера, модули дорожной карты, статусы обращений и чтения. Меню разделов не прокручивается: на компьютере это компактная колонка, на телефоне — плитки.

Язык интерфейса переключается кнопками ҚАЗ · РУС · ENG в верхней панели и тоже запоминается в браузере. Переводятся меню, кнопки, подписи, подсказки, уведомления, сообщения виртуального библиотекаря, названия промптов, вопросов базы знаний и занятий. Полные ответы базы знаний, тексты обращений, имена и другие демо-записи остаются на языке оригинала.

Генерация ответов ИИ и общее хранилище данных работают, когда страница открыта как артефакт Claude (ссылка «Демо с ИИ» выше). В обычном браузере интерфейс показывает «ИИ: без генерации» и «Локальный режим»; остальные функции работают.

## Сборка

Исходники лежат в `src/`. Скрипт собирает их в `dist/index.html`:

```sh
sh build.sh
```

## Проверка

Сценарии на Playwright открывают собранную страницу, проходят основные действия в обоих кабинетах и сохраняют скриншоты в `shots/`:

```sh
npm install
npx playwright install chromium
npm test
```

## Структура

```text
src/head.html    разметка, стили, светлая и тёмная темы
src/data.js      демо-данные: база знаний, каталог, журналы, планы, промпты
src/topics.js    база утверждённых тем ЕНУ для AI Topic Finder
src/commission.js экспертная комиссия и кабинет эксперта
public/          логотип: favicon, иконка для телефона, картинка для превью ссылки
src/i18n.js      словарь интерфейса: русский, қазақша, English
src/app1.js      утилиты, состояние, хранилище, обращения к ИИ
src/app2.js      поиск, рекомендации, цитирование, планер, аналитика
src/app3.js      интерфейс кабинета исследователя
src/app4.js      графики, кабинет сотрудника, модальные окна
src/app5.js      действия, ассистент, заявки, запуск приложения
tests/           сценарии проверки на Playwright
build.sh         сборка
dist/index.html  собранное приложение
```
